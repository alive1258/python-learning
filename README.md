# Python Learning Journey 🐍

I'm learning Python step by step, from programming fundamentals to Object-Oriented Programming (OOP), through hands-on practice, coding exercises, and small projects.

This repository contains my notes, practice code, and projects as I strengthen my Python programming skills.

## 📚 Course Modules

### Module 01: Python Fundamentals

- Introduction to Python and Environment Setup
- Running Python Code in Terminal and VS Code
- Basic Data Types and Variables
- Input, Output, and Type Casting
- Basic Operators and Comparisons
- Conditional Statements
- `while` Loops
- `for` Loops and `range()`

### Module 02: Functions and Lists

- Introduction to Functions
- Default Parameters and `*args`
- `**kwargs` and Multiple Return Values
- Local and Global Scope
- Built-in Functions and Importing Modules
- Lists, Indexing, and Slicing
- List Methods
- List Comprehensions

### Module 03: Python Data Structures and Advanced Topics

- Strings, Immutability, and String Methods
- Tuples and Tuple Methods
- Sets and Set Methods
- Dictionaries and Dictionary Methods
- Built-in Modules: `time`, `math`, `random`, and More
- Installing External Packages: PyAutoGUI and OpenCV
- Exception Handling: `try`, `except`, and `finally`
- File Reading and Writing
- Lambda Functions

### Module 05: Object-Oriented Programming (OOP)

- Introduction to Classes
- Creating and Using Methods
- Constructors and `__init__()`
- Class Attributes vs. Instance Attributes
- Bank Account: Deposit, Withdrawal, and Balance Management
- Shopping Cart, Checkout, and Price Calculations
- School Management System Using Multiple Classes
